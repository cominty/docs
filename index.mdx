Cominty is an AI platform for building agents that work with your company's
knowledge and data sources. This documentation covers how to get started,
concept guides, MCP integrations, the Python and JavaScript SDKs, and the API
reference.

<Tip>
  New here? Start with the [Quickstart](/quickstart) to send your first message,
  then dive into the [Python SDK](/sdk/overview) or the
  [JavaScript SDK](/js-sdk/overview).
</Tip>

## Official SDKs

Two official, fully typed SDKs wrap the API. Both cover the same features:
chat and streaming, threads, files, memory, capabilities, agents, skills,
sources, and MCP integrations.

<CardGroup cols={2}>
  <Card title="Python SDK" icon="python" href="/sdk/overview">
    `pip install cominty-sdk`. Async client for Python 3.9+.
  </Card>
  <Card title="JavaScript SDK" icon="js" href="/js-sdk/overview">
    `npm install @cominty-ai/sdk`. TypeScript client for Node, Bun, Deno, and
    edge workers, with zero dependencies.
  </Card>
</CardGroup>
