The Cominty API is a standard HTTPS/JSON API. This guide takes you from zero to
your first authenticated request.

## Prerequisites

Before you begin, you need:

- A **Cominty account**
- A **Cominty API token** (see the next step)

The base URL for the API is `https://ds.cominty.com`.

## Get started

<Steps>
  <Step title="Get your API token">
    Create an API token from the Cominty dashboard. You'll pass it on every
    authenticated request in the `x-cominty-token` header.

    Keep it secret — treat it like a password.

    ```bash
    export COMINTY_TOKEN="your-api-token"
    ```
  </Step>
  <Step title="Check connectivity">
    Confirm you can reach the API with the public health endpoint (no auth
    required).

    ```bash
    curl https://ds.cominty.com/status
    ```
  </Step>
  <Step title="Make your first authenticated call">
    List the agents in your workspace by sending your token in the
    `x-cominty-token` header.

    ```bash
    curl https://ds.cominty.com/agents \
      -H "x-cominty-token: $COMINTY_TOKEN"
    ```

    A `200` response with a JSON body means your token works. You're ready to go.
  </Step>
</Steps>

<Tip>
  Explore every endpoint — agents, chat, skills, documents, and more — in the
  [API Reference](/api-reference). Each page includes a live playground where you
  can try requests with your own token.
</Tip>
